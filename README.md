# practice-python-guess-number
Beginner Python project - number guessing game
This is a simple Python practice project.

## Description

This program is a number guessing game.

The user enters two numbers to define a range.

The computer selects a random number between them.

The player has 5 chances to guess the correct number.

After each guess:

- If the guess is bigger, the program says it is too high.
- If the guess is smaller, the program says it is too low.

The program also shows the remaining chances.

If the user fails, the correct number is shown.
